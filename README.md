# 🪞 THE MIRROR INVESTIGATION

**A narrative-driven cybersecurity CTF.**

₹50 crore has disappeared from NovaVault. The evidence doesn't add up, identities remain uncertain, and someone known as **ECHO** is still out there.

You're assigned to investigate. Six challenges stand between you and the truth.

## 🔎 The Case Files

| # | Challenge | What to Expect |
|---|---|---|
| 01 | **The SetUp** | Cryptography and hidden messages |
| 02 | **Digital Footprints** | Digital forensics and evidence analysis |
| 03 | **Hidden in Plain Sight** | Steganography and visual pattern recognition |
| 04 | **Chasing Shadows** | OSINT and digital identity investigation |
| 05 | **Behind the Login** | Web security and application analysis |
| 06 | **Whoami** | Logical deduction and the final reveal |

## 🛠️ What You'll Need

- Curiosity and attention to detail
- Basic command-line and scripting skills
- A willingness to investigate unfamiliar tools and techniques

## 📌 Rules of Engagement

- Investigate only authorised challenge systems.
- Follow the evidence, verify your findings, and keep track of useful clues.
- Avoid sharing flags or spoilers with other players.
